学习率衰减 + 容量 + 适度增强

余弦衰减把 lr 从 0.001 逐步降至 0.00005。加宽版为 Conv 16/32/64、Dense 128。训练增强为每张图独立的 ±10° 旋转、约 ±2px 平移与 0.9–1.1 缩放；不做翻转，验证和测试图不增强。

保留 GPU 图，真正改变学习率

学习率放在 GPU scalar tensor 中并原位更新，避免 CUDA Graph 把初始学习率固化。已验证学习率降为 0 时参数停止更新，回放时增强随机数也确实变化；尾 batch 后的继续回放保持正确。
