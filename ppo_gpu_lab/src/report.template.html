第一步：批量做数学运算。 原版用 JavaScript 嵌套数组逐样本前后向；GPU 版用矩阵批处理，环境也按批演进。状态、动作、优势和优化器状态持续驻留显存。

状态为 [x, ẋ, θ₁, θ̇₁, θ₂, θ̇₂]。环境在每步解 M(q) q̈ = N(q,q̇,F)，角度相对竖直方向。位置超出 ±2.4m 或任一角度超过 ±12° 时终止，奖励 −100。

r = 1 − 0.5(θ₁² + θ₂²) − 0.1x² − 0.01(ẋ² + θ̇₁² + θ̇₂²) δₜ = rₜ + γ · (1 − terminalₜ) · V(sₜ₊₁) − V(sₜ) Aₜ = δₜ + γλ · (1 − episode_endₜ) · Aₜ₊₁

Actor 是两个 ReLU 隐藏层和线性输出；Critic 结构相同但只输出价值。使用固定 rollout 的旧概率，计算概率比，按全批优势标准化后做多轮随机小批量更新。

ρ = exp(log π(a|s) − log π_old(a|s)) L_actor = −E[min(ρA, clip(ρ,1−ε,1+ε)A)] − βH L_critic = ½ E[(V − return)²] H = log σ + ½ log(2πe)

默认版本保留源页面的动力学表达式，便于数值对照；另有 --physical 选择独立修正的绝对角双摆模型。算法背景：PPO 原论文；实现依据：PyTorch CUDA Graph 文档。

03

先修复，再比较

原页面问题实际影响提取版的处理
Mat.map 回调索引错位row.map(func) 传入值、列号、整行数组；backward / Adam 却按值、行号、列号访问。复现得到非有限梯度。最小 JS 修复显式传 (value,row,col)；保留未改原始核心。
Entropy 符号反了原版把高斯熵写成负值，惩罚了探索。使用正确高斯熵，并在最小化损失中减去 βH。
裁剪动作后算高斯密度边界动作的实际分布含点质量，不等于普通高斯密度。保存并训练 latent Gaussian action；仅向环境传递裁剪动作。
GAE bootstrap 状态错位原版用最后一个 sₜ 代替 sₜ₊₁；时间上限未标记 episode 边界，可能串接不同 episode。存储真实下一状态价值；真正终止清零 bootstrap，时间截断仍 bootstrap 但切断 GAE 递推。
动力学与绘制的角度约定不一致原式竖直附近重力恢复、质量矩阵包含额外交叉项；不能直接视为真实倒立摆。默认如实保留；独立提供物理修正版并单独报告，避免混淆任务。

数值证据

检查最大绝对误差结果

256 组随机状态覆盖原终止边界附近。单步对照包括状态、奖励、done；legacy 单次更新使用相同 JS 权重、样本和原版目标函数。GAE 测试显式区分真终止与时间截断。容差验证不是长轨迹逐位一致的承诺。
