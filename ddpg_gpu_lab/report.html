测量环境是共享桌面 GPU：探测时有图形程序占用约 1.6 GiB 显存，运行期间也观察到其他计算任务。这里报告当前条件下的五轮分布，不代表独占 GPU 的极限性能。原版基线是同一台 desk 上的 Node.js 核心，不含 DOM 绘图与演示等待。

哪部分是可归因的系统优化？

普通 GPU、CUDA Graph、编译学习更新、编译整个循环：这些行使用相同的 FP32 小网络和批量 Adam 算法。固定为 1 env / B64 时，主要变化是执行方式，能用于判断编译与图重放的收益。

哪部分不能当作同算法提速？

原 JS 的 64 次串行 critic SGD，被改成 1 次批量 Adam；32 环境版本每 32 条新样本才更新一次。它们改变了优化轨迹与数据复用比例。原版倍数、并行采样倍数不能直接解释为“达到相同策略质量快多少”。

01 / ACT

02 / COLLECT

03 / LEARN

Bellman 目标训练 critic

04 / TRACK

目标网络 Polyak 更新
每步 τ = 0.005

两张小网络，四份参数

Actor 为 4 → 32 → 16 → 1，隐藏层 ReLU，输出 tanh × 10，共 705 参数。Critic 将状态与动作拼接，5 → 32 → 16 → 1，共 737 参数。加上两份目标网络，共 2,884 个参数。

原始初始化使用均匀分布 ±√(2 / fan-in)，输出层 ±√(1 / fan-in)，偏置 ±0.005。优化版保留此规则，不暗中扩大网络。

y = r + 0.99 (1 − d) Q_target(s′, μ_target(s′)) L_critic = ½ mean[(Q(s,a) − y)²] L_actor = −mean[Q(s, μ(s))] w_target ← 0.995 w_target + 0.005 w

这不是 swing-up 任务

摆从上方的小扰动开始：x = ẋ = 0，θ 与 θ̇ 均匀分布在 [−0.01, 0.01]。每步 0.02 秒，力限制 ±10 N，|x| > 2.4 m 或 |θ| > 12° 时终止。

未倒下：r = 1 − 0.5 |θ / (π/15)| − 0.1 |x / 2.4| 倒下：r = −10 无效数值：r = −100 200 步训练时间截断：重置，但 d 仍为 false

UI 中的 Noise StdDev 实际实现是均匀噪声 ε ∈ [−2, 2]，并非高斯标准差 0.2。移植版本保留了原来的均匀分布。

展开：原始物理方程与移植边界
M = 1.0, m = 0.1, ℓ = 0.5, g = 9.8, Δt = 0.02 z = (F + mℓ θ̇² sin θ) / (M + m) θ̈ = (g sin θ − cos θ · z) / [ℓ (4/3 − m cos²θ/(M+m))] ẍ = z − mℓ θ̈ cos θ / (M + m) [x, ẋ, θ, θ̇] ← [x + Δt ẋ, ẋ + Δt ẍ, θ + Δt θ̇, θ̇ + Δt θ̈]

位置和角度使用旧速度，不能误换成半隐式积分。当前优化器的物理常量固定为源网页默认值；任意 UI 参数的运行时修改尚未移植。保留无效动作清零与无效状态惩罚。原版 actor 的非有限梯度跳过分支改成训练日志检查并报错，不能声称逐步完全等价。

慢在循环与数据路径，不在模型大小

源实现的开销已落地的改动性质
Critic 每个 batch 连续更新 64 次矩阵乘法计算批量梯度，一次更新算法语义改变
大量 Array.map / transpose / 小对象张量矩阵运算；Inductor 融合逐元素计算计算路径优化
软更新重复 JSON 深拷贝设备内原地 lerp，目标网络常驻数据路径优化
单环境 + CPU 回放GPU 仿真、环形缓冲、采样、学习设备驻留；并行数可配
每步重绘全部历史损失训练无 UI；稀疏记录，完成后本地回放移除逐步增长的绘图成本
每个小算子从 Python 提交静态形状 + CUDA Graph 整步重放减少 CPU 调度与启动开销

回放池为 50,000 × 11 个 FP32 值，约 2.10 MiB；索引、优化器、计算临时空间和 CUDA 图分配另计。本次 GPU 训练的 PyTorch 峰值已分配显存约 31.2 MiB（不含 CUDA 上下文、其他进程与分配器未使用的保留显存）。无需先上多卡、FP16 或更大的网络。

如何解释这组实验

主要 GPU 实验使用 32 环境、batch 256、warm-up 1,024 条随机样本、20,000 次更新（另加 warm-up 的 640,000 条采样）。γ、τ、网络与物理参数保留源默认值，优化器改为 Adam，学习率 actor 10⁻⁴ / critic 10⁻³。

200 步成功并不代表无限平衡。另做 1,000 步（20 秒）评估，并公开所有种子的结果。没有用 LQR、模仿学习、额外奖励或筛选最佳中间权重来替代 DDPG。

这些小规模测试不能证明对任意初态都稳定，也没有统计显著性结论。加速结论基于计算测量；策略质量结论仅限这里列出的训练预算与初态集合。
