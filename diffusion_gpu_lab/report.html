01 / MEASURED LATENCY

同样生成 5 张图，逐层拆开加速收益

每种方法完整预热一次，随后随机顺序交错测量 7 轮。条形为中位数，圆点为每轮原始值；悬停可查看耗时。

单位：毫秒 / 5 张图 · 深绿：全部 200 步 · 棕色：改变采样过程的 DDIM · 越短越快

计时边界

采用 CUDA 同步后的墙钟时间，包含随机噪声、完整反向链、最终 GPU→CPU 传输与 5 张 PNG 编码。保留原版未使用中间图的 CPU 拷贝。

不包含模型加载、CUDA 初始化、图捕获、Flask/HTTP、日志输出、SSH 和网络延迟。原版和优化版使用同一份 epoch 20 权重；不是 CPU 对 GPU 的比较。

这台 GPU 当时并非独占

后台有图形程序和其他 Python 任务，部分轮次出现明显变慢。所有测量均保留，未筛掉慢值，也未停止其他任务。

这些结果代表当时共享环境，不是硬件峰值。7 轮的 P10/P90 只描述这批测量的分布，不是置信区间。各轮进程状态保存在 benchmark.json。

02 / EXTRACTED CORE

原算法：学习噪声，再逐步去噪

核心来自 model_unet.py 和 app.py。保留三份原始文件，Git blob SHA 与指定 commit 完全匹配；core.py 只提取模型与扩散函数，去掉文件末尾的独立 smoke test。

MNIST28×28 灰度 → [−1, 1]
→
随机 t + 高斯噪声线性 β：0.0001 → 0.02
→
残差 U-Net32 / 64 通道 · GroupNorm
→
噪声预测 MSEAdam · lr=10⁻⁴ · B=64

训练目标保持不变

xₜ = √ᾱₜ x₀ + √(1−ᾱₜ) ε
L = E ‖ε − εθ(xₜ, t)‖²

αₜ=1−βₜ，ᾱₜ=∏αₛ。U-Net 共 660,129 参数，两级下采样/上采样、skip concat、SiLU 和 128 维时间嵌入。模型宽度和层数均未裁剪。

DDPM 200 步保持不变

μₜ = (xₜ − βₜ εθ/√(1−ᾱₜ)) / √αₜ
xₜ₋₁ = μₜ + √β̃ₜ z

t=0 时方差为零。图回放中的每一步仍使用新的随机噪声，时间索引继续前进；这些行为都做了检查。

改动实际实现语义与收益边界
五图合批5 次独立 B=1 → 一次 B=5U-Net 调用从 1,000 次变为 200 次；每个样本仍有 200 步。
状态与系数常驻 GPU预计算系数、缓存 200 个时间嵌入、只取最终图权重更新后必须重新构建采样器；演示过程图在计时之外另存。
单步 CUDA Graph固定地址保存图像、步数与输出，回放 200 次降低 Python 和 kernel 提交开销；固定 batch/尺寸，每个 worker 独立实例。
AMP + channels_last卷积自动混合精度，扩散状态与系数保留 FP32引入舍入差异；收益需要实测，本例没有稳定的大幅额外收益。
DDIM η=0在同一训练时间表选择 50 / 20 步；无 x₀ clipping改变反向采样过程。ε 网络复用，生成分布和图像不保证一致。
原始时间表本身有局限。 T=200 时末端 ᾱ≈，√ᾱ≈0.364，训练终点仍保留较多信号；生成却从纯高斯开始。这会影响生成质量。此次保留该设定以便公平比较；改成更充分的噪声日程需要重新训练和评估。

04 / TRAINING

训练也需要减少整步提交开销

原始网络、batch=64、Adam 与相同学习率。增加 FP32 CUDA Graph 后，把前向、损失、反向和 Adam 更新捕获在一个图里；数据、时间步和噪声每次更新。捕获预热后的权重与优化器状态会原位恢复。

每种方法 8 步预热；7 轮随机交错，每轮连续 20 个完整更新，测量同步墙钟时间。原版包含逐 batch 的 CPU→GPU 与 loss.item()；均不含 PIL/DataLoader/HTTP。无收益的布局和 AMP 配置也保留。

固定 512 张测试图与固定噪声、时间步。实线为 AMP 训练，虚线为 FP32 Graph 训练；两条都训练 20 轮、1,560 次更新。采样性能与上方图像统一使用 AMP 训练得到的同一份权重。

05 / VALIDATION

保留算法，给出可量化误差

随机性与边界

同种子重复回放可复现；不重置种子时输出会变化，避免捕获后冻结噪声。检查了 t=0 的零方差、完整 200 步的图回放和 10 步 Adam 更新。

上游 3 个 U-Net 测试也已通过。FP32 链路采用 2×10⁻⁴ 的最大绝对误差阈值，容纳浮点运算重排与 cuDNN 差异；不是逐位相等承诺。

精度与质量的区别

噪声预测 MSE 检查的是同一训练模型的数值行为，不是完整生成质量指标。AMP 梯度比较采用相同输入、时间步和噪声；相对 L2 误差记录在独立 JSON 中。
