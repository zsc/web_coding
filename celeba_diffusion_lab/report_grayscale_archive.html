训练配方

t = sigmoid(Normal(-0.8, 0.8²))
z_t = t × x + (1-t) × epsilon
x_pred = model(z_t, t)
loss = mean(((x_pred-x) / max(1-t, .05))²)

t=0 噪声，t=1 数据。两组直接预测干净图像，从零输出初始化。保持本实验的 [−1,1] 数据范围、AdamW lr=2e−4、500 步预热、梯度裁剪 1 和 EMA，未照搬大模型的数据集 μ/σ 标准化、大 batch 与优化器设置。采样不做中间裁剪。

LOCAL REFERENCES / CSTFT_JIT + CSTFT_JIT_ARC2FACE

两个 JiT 项目给出的启发

最关键的差异是预测目标

这两个实现直接预测干净 x，使用线性流 zₜ=t·x+(1−t)·ε，以速度空间 MSE 训练，再用 Euler/Heun 积分。当前 U-Net 则预测 ε，以 DDIM 从 ε 还原 x₀。JiT 路线避免了我们在高噪声端测到的 ε 误差乘约 157 后进入 x₀ 的还原过程；这使它值得作为下一项独立实验，但不保证自动消除分布差异。

这里的时间方向也相反：JiT 的 t=0 是噪声，t=1 是数据。不能只替换网络头，保留原训练与采样公式。

归一化并非逐图“风格归零”

ImageStats 用训练集的逐通道 μ/σ 做可逆变换，采样后恢复原尺度。每张图的明暗差异仍然保留；它不是把每张脸调成同样的亮度。

affine 与切块：代码和记录分别说明什么

JiT block 使用 RMSNorm + adaLN 的 shift/scale/gate，末层零初始化；无条件配置只用时间条件，没有显式的带噪图均值分支。cstft_jit 的可选 RPCAHead 另有 GroupNorm 后的 FiLM，但不是主实验默认配置。本轮借用条件调制和零残差初始化思路，单独验证全局输入。

CelebA 记录中，输出卷积头明显改善早期 patch 网格痕迹，但训练到 30,000 步后差距缩小；patch=8 的最终验证 loss 高于 patch=4。这是已有项目记录，本轮没有重跑，也不能把“patch 输出独立”理解成 Transformer token 之间没有注意力交互。

参考 CelebA 主实验约 130.4M 参数、30,000 × 1,024 = 3,072 万张次；本轮 A 是 6.34M、5,000 × 32 = 16 万张次。训练曝光相差 192 倍，先前观感不能单独证明 Transformer 胜过 U-Net。

根据这些差异，上方 D/E 先比较同一全局 affine U-Net 的 flow 配方，再与小型 patch=4 JiT+conv 对照，以区分配方和主干的收益。A/B/C 保持 ε 目标；上方 D/E 使用同一 flow 配方，进一步比较 U-Net 与 JiT+conv。

THE FAILURE / COLOR DISTRIBUTION

偏色是分布失配，需要单独检验

基础模型的五官逐渐清楚，但确定性采样的整体颜色仍然偏离真实数据。ε-MSE 下降并不保证这一分量学对了。RGB 归一化与图像还原的逐像素往返误差为 0；普通 FP32 也出现相同偏色。

误差以图像归一化到 [−1,1] 的单位表示。t=999 的误差放大系数约 157；简单复制带噪图的空间均值，ε 的 DC RMSE 仅约 0.0020，明显低于网络的 0.0132。

改裁剪并没有解决学习问题

保留原 ε 的版本颜色均值接近一些，但图与图之间的颜色标准差被压到约 1.5–1.8 / 255；取消裁剪则有约 56% 输出像素超出范围。只看颜色均值会漏掉新的分布问题。

模型与训练

DiT 的 patch size 在这里没有直接对应参数：U-Net 逐级处理 64² → 32² → 16² → 8² 特征，并保留各分辨率的 skip connection。最接近的结构变量是下采样倍率与 attention 所在分辨率；这次尚未做这两个变量的消融。

四级 U-Net，通道 32 / 64 / 128 / 128，每级 2 个残差块；在 16×16 与瓶颈使用注意力。6,338,499 个参数，从随机权重训练。

1,000 个线性噪声步，β 从 10⁻⁴ 到 0.02，预测 ε；终点 ᾱ≈4.04×10⁻⁵。AdamW，学习率 2×10⁻⁴，前 500 步预热，梯度裁剪 1.0；EMA 最高衰减 0.999。

继承 MNIST 改进版的噪声日程、EMA 与裁剪 DDIM。网络容量和数据都改变，因此这是新的 CelebA 实验。

运行优化

JPEG 只解码一次，以 uint8 缓存；按批次传入 GPU。channels-last + FP16 自动混合精度训练，FP32 主权重；采样每个去噪步骤捕获为 CUDA Graph。

完整保存优化器、GradScaler、EMA 和随机数状态，支持断点续训。采样预览不改变训练的随机数流。

训练试跑步耗时分配峰值

合成数据，10 次预热 + 35 次测量；不含 EMA、I/O 和验证。各试跑负载不同，仅用于选择 batch，不能当作严格的 AMP 加速比。
